POORNIMA JAT — PHARMACY PORTFOLIO
=================================

FILES
- index.html : portfolio structure and content
- style.css  : dark navy / pink / violet visual design, responsive layout and animations
- script.js  : mobile menu, scroll reveals, contact mailto form and local portfolio FAQ assistant

SETUP
1. Keep index.html, style.css and script.js in the same folder.
2. Put Poornima's approved portrait in the same folder and name it exactly:
   poornima-jat.jpeg
3. Open index.html locally or upload all files to the root of a GitHub Pages repository.
4. Commit and push. Then hard refresh the website (Ctrl + F5).

PRIVACY / ACCURACY
- Phone number is intentionally displayed as XXXXX-XXXXX.
- The contact form uses mailto and does not store form submissions.
- The assistant is a local FAQ bot, not a generative AI model. It only answers curated portfolio questions and avoids inventing unverified details.
- A resume PDF, specific certifications, work experience and projects have not been supplied/verified for Poornima, so the page does not fabricate them.
- To use a custom email destination, edit the mailto line in script.js.
- External Google Fonts need internet access; fallback fonts are defined.
